
# Kairo

App inteligente de organizacao pessoal — Progressive Web App.

## Funcionalidades

- Dashboard com métricas diárias e Kairo AI
- Agenda diária e semanal
- Gestão de tarefas com prioridades e filtros
- Rastreamento de hábitos com streaks
- Planejamento inteligente de blocos de tempo
- Suporte offline via Service Worker (PWA)

## Como usar

Abrir `index.html` num browser moderno (Chrome, Edge, Firefox).
Para instalar como PWA, usar a opção "Instalar app" no browser.

## Tecnologias

- HTML5 + CSS3 + JavaScript (vanilla)
- Lucide Icons
- Inter (Google Fonts)
- PWA: manifest.json + Service Worker (sw.js)
